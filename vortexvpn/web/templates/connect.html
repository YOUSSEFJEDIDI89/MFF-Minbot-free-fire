VortexVPN هو VPN عادي وشرعي يحمي خصوصيتك ويشفّر اتصالك. لكن لازم تعرف:

  • ✅ ما يفعله: تشفير ترافيكك، إخفاء عنوان IP الحقيقي، تجاوز قيود الشبكة، أمان على WiFi عام.
  • ✅ ما يفعله: يسمح لك بالاتصال من هاتفك إلى السيرفر وتصفح الإنترنت كأنك على السيرفر.
  • ❌ ما لا يفعله أبداً: لا يحسّن أداء الألعاب (VPN يضيف قفزة إضافية → غالباً يزيد الـ ping).
  • ❌ ما لا يفعله أبداً: لا ينقل عبء المعالجة من هاتفك إلى هاتف آخر. هذا مستحيل تقنياً.
  • ❌ ما لا يفعله أبداً: لا يخترق anti-cheat ولا يعطيك ميزة في الألعاب.

إذا كنت تبحث عن أداة للغش في الألعاب، VortexVPN ليس لها. هذا اختيار مقصود.

الخطوة 1: اختر تطبيق VPN على الهاتف

VortexVPN يستعمل بروتوكول مخصص (UDP + AES-256-GCM). حالياً، الطريقة الأسهل للهاتف هي:

التطبيقالمنصّةملاحظة
OpenVPN Connect Android / iOS متوفر في Play Store و App Store مجاناً. (يتطلب إعداد ملف .ovpn — لم يُولّد بعد)
WireGuard Android / iOS أسرع وأبسط. (يتطلب دعم بروتوكول WireGuard — في قائمة المهام)
عميل Python Linux / Termux python -m vortexvpn.core.tunnel_client --host SERVER_IP --port 4433 --user YOUR_USER --password YOUR_PW

⚠️ حالياً، العميل الأكثر اختباراً هو عميل Python. تطبيقات OpenVPN/WireGuard تحتاج توليد ملف تعريف — هذه ميزة قادمة.

الخطوة 2: الاتصال (الطريقة الأسهل حالياً)

  1. على الهاتف الآخر، ثبّت Termux (من F-Droid، النسخة في Play Store قديمة):
    https://f-droid.org/packages/com.termux/
  2. في Termux، ثبّت Python: 
    pkg install python python-dev git
  3. انسخ المشروع: 
    git clone https://github.com/YOUSSEFJEDIDI89/MFF-Minbot-free-fire.git
cd MFF-Minbot-free-fire
pip install -r requirements.txt
  4. أنشئ مستخدم على السيرفر (من لوحة الويب في المتصفح → المستخدمون → إضافة)، ثم على الهاتف: 
    python -m vortexvpn.core.tunnel_client \
  --host {{ server_ip }} \
  --port {{ tunnel_port }} \
  --user USERNAME \
  --password PASSWORD
  5. عندما ترى "handshake completed" — الهاتف متصل بالـ VPN.

ماذا يحدث بعد الاتصال؟

بمجرد اتصال الهاتف بـ VortexVPN:

  • 🌐 كل ترافيك الإنترنت من الهاتف يمر عبر السيرفر (مشفّر).
  • 🔒 عنوان IP الظاهر للهاتف يصبح عنوان السيرفر.
  • 📡 يمكنك تصفح الإنترنت، استخدام التطبيقات، إلخ — كلها عبر السيرفر.
  • 🎮 الألعاب: ستعمل، لكن الـ ping سيرتفع غالباً بسبب القفزة الإضافية. هذا طبيعي لأي VPN.

مشاكل شائعة وحلولها

الهاتف لا يصل تأكد أن منفذ UDP {{ tunnel_port }} مفتوح في جدار الحماية على السيرفر (sudo ufw allow {{ tunnel_port }}/udp)
الـ ping عالي في الألعاب هذا متوقع. VPN يضيف قفزة. للحصول على أقل ping، اختر سيرفر قريب جغرافياً.
انقطاع الاتصال كل دقيقة تحقق من NAT/router على السيرفر. حافظ على جلسة نشطة بإرسال ping دوري.
Termux لا يبني TUN على Android بدون root، TUN غير متاح. استعمل وضع socket-only (افتراضي في عميل Python).
